① コマンドパレットの使い方

キーボード操作に慣れている方向けの、テキスト入力によるコマンド実行方法です。

  1. 画面下部のコマンド入力欄に、/から始まるコマンドを入力してEnterキーを押します。
  2. コマンドには3つのモードがあります。@0＝通常（ページ・OCR操作）、@1＝数式、@2＝システム（表示・DLC管理）。/command mode @0 のように入力すると切り替えられます。
  3. どのモードからでも /all command と入力すると、今のモードで使えるコマンドの一覧がその場に表示されます（このページの内容と同じです）。
💡 数式や図形の挿入は、コマンド入力よりも、ツールバーの「∑数式」ボタンからタップ操作で組み立てる方法の方が直感的です（詳しくは使い方ガイドをご覧ください）。コマンドは主に、キーボード操作に慣れている方向けの早道として用意しています。

② コマンド一覧

@0：通常モード
@1：数式モード
@2：システムモード
/textページ中央にテキストボックスを作成
/feedback意見・アンケート画面を開く（利用状況の書き出しや、集計ページへのリンクもここ）。どのモードでも使えます
/aocrAOCRv01エンジンの状態表示・オン／オフ・方式の切り替え（/aocr on、/aocr off、/aocr mode balanced）。AOCRv01.js が必要。どのモードでも使えます
/aocr2AOCRv02エンジン（試作）の状態表示・オン／オフ・使い方の切り替え（/aocr2 on、/aocr2 off、/aocr2 mode compare|use、/aocr2 build）。AOCRv02.js が必要。部分OCRにだけ使います。どのモードでも使えます
/noteノートモード：用紙（罫線・方眼・コーネル式など）を選ぶ画面を開きます。どのモードでも使えます
/note list使える用紙の一覧を表示します
/note new 用紙名その用紙で新しいノートを作ります（例：/note new コーネル）。ページ数は、画面で最後に選んだ数です
/note add 用紙名いまのページの次に、その用紙のページを1つ追加します（例：/note add 方眼）
/note change 用紙名いまのページの用紙だけを変えます。書き込みは残ります（例：/note change 罫線）
/inputPDF/画像を追加読み込み（縦横選択→自動でその範囲をOCR）
/cameraカメラで撮影して画像挿入・OCR
/output [pdf|image]作成した全ページを書き出す（省略時はPDF）
/delete{N}Nページ目を削除
/ocr {N}Nページ目を再OCR（最初の結果は削除されます）
/slide ocr {N}Nページ目を再スライドOCR（最初の結果は削除されます）
/out of ocr{N}Nページ目のOCR除外範囲（図・写真など）を自動検知
/all ocr全ページを再OCR（最初の結果は削除されます）
/all slide ocr全ページを再スライドOCR（最初の結果は削除されます）
/all out of ocr全ページのOCR除外範囲を自動検知
/command mode @0|@1|@2コマンドモードを切り替える
/all commandこのコマンド一覧を表示
/text ○LaTeXの○を数式テキストボックスとして作成（例：/text x^2+1）
/all kigou数学記号一覧から選んで数式エディタに挿入
/ofset text ○○を手書き風の書体で作成
/all commandこのコマンド一覧を表示
v3.6以降、数式はタップ式のボタンと数字・変数キーパッドだけで組み立てられるようになりました（ツールバーの「∑数式」ボタン）。コマンド入力はLaTeXを直接書ける方向けの方法です。
/note mode @1通常のシステム（全機能）
/note mode @2ペン・消しゴム機能なし
/note mode @3画像・動画・URL・グラフ挿入なし
/note mode @4ペン・消しゴムに加え画像・動画・URL・グラフ挿入もなし
/note mode @5部分OCRの精度を優先（画像・動画・URL・グラフ挿入は使用不可）
/tool upツールバーを上端表示に切り替える（ページ一覧が見やすくなる）
/tool sideツールバーを左（通常）表示に戻す
/test mode onテストモードON（v4.5で追加：数式パレットの「よく使う公式」、ノート内のリンク・動画をブロック。学校のテスト時などに）
/test mode offテストモードOFF（v4.5で追加）
/import dlc追加DLC（.jsファイル）を選んで取り込む（複数取り込み可）
/dlc on [番号]DLCを有効にする（番号省略ですべて）
/dlc off [番号]DLCを無効にする（番号省略ですべて）
/dlc remove 番号指定した番号のDLCを削除する
/dlc list取り込み済みDLCの一覧と番号を表示する
/dlc checkDLCのバージョン照合（選んだ版・保存内容・実際に読み込まれた版・画面上のバッジ表記が合っているか）を確認する
/all commandこのコマンド一覧を表示

③ コマンド検索

気になるコマンドのキーワードを入力すると、①②の一覧から一致する行だけを表示します。

④ 困ったときは

  • コマンドが実行できない → 先頭に / を付け忘れていないか確認してください。
  • 思ったモードのコマンドが出てこない → 今どのモード（@0/@1/@2）か、入力欄の左のプロンプト表示（@0 / @1 / @2）で確認できます。
  • その他のご質問・不具合報告 → GitHubリポジトリからご連絡ください。
