アプリ画面左のツール一覧にある「>_ コマンド」ボタンを押すと、画面左側にコマンドパレットが開きます。 キーボード（iPad・iPhoneはフリック入力）で / から始まるコマンドを入力し、Enterで実行します。 現在のモードは常に画面左上に表示され、モードによってプロンプト記号（入力欄の左に出る印）が変わります。
コマンドの先頭に付くモードの記号（@0・@1・@2）は、アプリ内では常に /command mode ○ でどのモードからでも切り替えられます。

@0 ― 通常コマンド

>_

ページの操作・OCR・書き出しなど、ノート全体に関わる基本のコマンド群です。起動時はこのモードから始まります。

コマンド説明
/textページの真ん中にテキストボックスを作成します。
/inputPDFや画像を追加で読み込みます。読み込み後、縦書き/横書きを選択すると、そのページ範囲だけ自動でOCRします。
/cameraカメラで撮影し、画像として挿入するか、新しいページに追加してOCRします。
/output作成したページすべてを書き出します。/output pdf または /output image で形式を指定できます（省略時はPDF）。
/delete{N}N ページ目を削除します。例：/delete{3}
/ocr {N}N ページ目を再OCRします。最初の認識結果は削除されます。
/slide ocr {N}N ページ目を再スライドOCR（走査線で帯ごとに認識する方式）します。最初の結果は削除されます。
/out of ocr{N}N ページ目のOCR除外範囲（文章から外れた画像・図など）を自動検知します。
/all ocr全ページを再OCRします。最初の認識結果は削除されます。
/all slide ocr全ページを再スライドOCRします。最初の結果は削除されます。
/all out of ocr全ページのOCR除外範囲を自動検知します。
/command mode ○コマンドモードを切り替えます。○には @0 ・ @1 ・ @2 が入ります。どのモードからでも使えます。
/all command現在のモードで使えるコマンドの一覧を表示します。
>_ /ocr {2} ページ 2 を再OCRしています...（最初の結果は削除されます） ページ 2 のOCRが完了しました

@1 ― 数式専用コマンド

\_

数式やLaTeX記号をすばやく挿入するためのモードです。

コマンド説明
/text ○○にLaTeXの数式を書くと、そのまま数式のテキストボックスとして作成されます。例：/text x^2+1
/all kigouすべての数学記号（分数・根号・ギリシャ文字など）から選んで数式エディタに挿入できます。
/ofset text ○○の文字列を、手書き風の書体でそのまま画像として作成します。
/all commandこのモードのコマンド一覧を表示します。
\_ /text \frac{-b \pm \sqrt{b^2-4ac}}{2a} 数式を挿入しました: \frac{-b \pm \sqrt{b^2-4ac}}{2a}

@2 ― システムコマンド

$_

アプリの機能構成そのものを切り替えるモードです。

コマンド説明
/note mode @1通常のシステム（すべての機能が使えます）。
/note mode @2ペン・消しゴム機能がないシステム。
/note mode @3画像・動画・URL・グラフの挿入機能がないシステム。
/note mode @4ペン・消しゴムに加え、画像・動画・URL・グラフの挿入機能もないシステム。
/note mode @5部分OCRの認識精度を優先するシステム（その代わり画像・動画・URL・グラフの挿入機能は使えません）。
/tool upツールバーを画面上端の横並び表示に切り替えます。ページ一覧やツールバー自体が見やすくなります。
/tool sideツールバーを左側（通常）表示に戻します。
/import dlc追加DLC（.jsファイル）をファイルから選んで取り込みます。複数取り込むこともできます。一度取り込めば、次回このノートを開いたときも自動的に読み込まれます。
/dlc on [番号]DLCを有効にします。番号を省略するとすべてのDLCが対象になります（ページが再読み込みされます）。
/dlc off [番号]DLCを無効にします。番号を省略するとすべてのDLCが対象になります（ページが再読み込みされます）。
/dlc remove 番号指定した番号のDLCを削除します（ページが再読み込みされます）。
/dlc list取り込み済みのDLC一覧と、それぞれの番号・オン/オフ状態を表示します。
🧩ボタン画面上部の🧩ボタンからも、取り込み・個別のオン/オフ・削除ができます（コマンド操作が難しい場合はこちらが簡単です）。
/all commandこのモードのコマンド一覧を表示します。
$_ /note mode @5 ノートモードを @5 に切り替えました
DLC（追加コンテンツ）について： /import dlc で選ぶ .js ファイルは、 複数取り込むことができ、それぞれ個別にオン/オフ・削除ができます。 このノートの中身（ページやOCR結果など）に自由にアクセスできるプログラムです。 取り込み時に確認のダイアログが出るので、内容をよく確認したうえで、 信頼できる配布元のファイルだけを取り込んでください。ファイルは、なくさないよう index.html と同じフォルダに置いておくことをおすすめします。
上記以外にも、将来のコンテンツ追加や拡張ツールのための試験的なモードが内部的に予約されていますが、一般には非公開のため本ページには記載していません。
